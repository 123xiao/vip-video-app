# 全网 VIP 视频解析

一个美观实用的在线 VIP 视频解析网站，支持爱奇艺、腾讯视频、优酷、芒果 TV 等各大视频平台的 VIP 内容免费观看。

![网站预览](https://picsum.photos/800/400)

## ✨ 特点

- 🎬 **全平台支持** - 支持爱奇艺、腾讯视频、优酷、芒果 TV、搜狐视频等各大视频平台
- 🌈 **美观界面** - 采用现代化 UI 设计，响应式布局，支持暗黑模式
- 🔄 **播放历史** - 自动保存观看记录，方便重复访问
- ⚡ **快速解析** - 接入高速稳定的解析接口，快速加载视频
- 📱 **移动友好** - 完美适配手机、平板等各种设备

## 🚀 技术栈

- [Next.js 15](https://nextjs.org/) - React 框架
- [React 19](https://reactjs.org/) - 用户界面库
- [TailwindCSS 4](https://tailwindcss.com/) - CSS 框架
- [TypeScript](https://www.typescriptlang.org/) - 类型检查

## 📦 安装与运行

### 前提条件

- Node.js 18.0.0 或更高版本
- npm 或 pnpm 或 yarn

### 安装依赖

```bash
# 使用 npm
npm install

# 或使用 pnpm
pnpm install

# 或使用 yarn
yarn install
```

### 开发环境运行

```bash
npm run dev
# 或
pnpm dev
# 或
yarn dev
```

在浏览器中打开 [http://localhost:3000](http://localhost:3000)，即可看到应用运行效果。

### 生产环境构建

```bash
npm run build
npm run start
```

## 🔧 使用方法

1. 在输入框中粘贴您想要观看的 VIP 视频链接
2. 点击"立即播放"按钮
3. 等待视频加载完成后，即可观看

支持的网站包括但不限于：

- 爱奇艺（iqiyi.com）
- 腾讯视频（v.qq.com）
- 优酷（youku.com）
- 芒果 TV（mgtv.com）
- 搜狐视频（tv.sohu.com）
- PPTV（pptv.com）
- 乐视视频（le.com）

## 📝 常见问题

- **视频加载慢怎么办？** - 可能是网络问题或解析接口暂时不可用，请稍后再试。
- **为什么有些视频无法解析？** - 部分新上线或特殊保护的内容可能无法解析，解析接口会不断更新。
- **使用这个工具安全吗？** - 本工具仅提供视频解析服务，不会收集个人信息，但建议不要在解析页面输入敏感信息。
